# P0/P1 状态运行时

运行时维护 `WorldState`，通过显式的 `WorldAction` 推进时间、切换地点、更新手机已读状态与日程。前端的六类面板读取同一个状态源，Vue 组件不各自维护互相冲突的世界存档。

状态类型目前在 `src/frontend/types.ts`，初始示例数据和纯状态转换在本目录实现。正式接入后，Bridge 将状态写入当前聊天的 `unread_city` 变量；其中 `story` 数组保存界面内的玩家输入与叙事。原生聊天楼层不受这些界面内记录更新。

模型输出负责叙事，不负责任意改写数值，也不作为可执行代码或自动状态补丁。状态转换完成后再传入叙事上下文；生成期间的退出、聊天切换、失败和迟到回复由 Shell 会话边界处理，不能把结果提交到其他聊天。

当前桥接仅支持单人聊天，叙事生成要求 SillyTavern 的 Chat Completion 接口（`mainApi = openai`，不限定供应商）。取消先使本次结果失效，再尝试通过生成 ID 停止本请求；助手极早取消竞态下，上游工作可能继续，但结果不得提交。不会调用全局停止生成来影响其他脚本或原生聊天。

这是原型运行时，示例人物、地图、日程和数值不等于完整校园模拟。复杂 NPC 自主行动、全量日程规划、通用事件去重与历史存档迁移，需各自实现与验收；`src/schemas/` 中旧协议草案不会自动约束运行时。
