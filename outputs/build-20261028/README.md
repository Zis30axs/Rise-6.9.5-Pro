1. **基于核心变量的疾病与健康系统**：

     - **胃痛与虚脱**（严重空腹饥饿）：饱腹 <= 15 且食物能量 <= 150，胃部隐痛反酸。
     - **神经衰弱**（严重高压与精神崩溃）：压力 >= 75 且精神 <= 35，胸闷心悸焦虑，卧床睡眠休养恢复效率折损。
     - **重度疲劳综合征**（精力 <= 5 且健康 < 35）：严重体能透支，出行消耗 +50%，禁止重体力搬运兼职。
   - **全套康复与调理途径**：
     - **便利店 4 款非处方医药**：感冒退热颗粒（¥480）、温和健胃整肠片（¥420）、草本安神舒压水（¥560）、医用营养机能饮（¥320），放入背包随时使用。

     - **自然休养机制**：寝室与私人居所长休卧床、补充温热饮食，身体机能自然改善后病症自然痊愈并记录手记。
   - **沉浸式健康诊断面板**：
     - 状态面板新增“身体健康与不适”栏目，呈现当前体感、病症严重程度、具体症状与自然调理建议；无异常时显示良好健康提示。
   - **小说正文与大模型叙事注入**：
     - `bridge.ts` 与 prompt 上下文自然注入当前疾病与症状，引导模型生动描写角色的体感不适与疗愈过程。
   - **四主角完全独立**：
     - 素世、祥子、艾玛、玲奈子身心与疾病状态相互隔离，存档 100% 保持历史向后兼容。
2. **南门工地实景背景支持**：
   - 增加南门施工现场白昼实景背景，支持小说与室内外视觉呈现。

   - 平衡办公室工资与体力劳动，引入高压限制（压力达到 70 时必须休整）。
4. **新 NPC 风堇（雅辛忒丝）与街区全科诊所日夜背景、对话立绘及每周谈心疗愈**：
   - **人物世界书设定**：`src/worldbook/fengjin-clinic.json` 注册常驻主治医师风堇（Hyacinthia，称号「摇光的医师」），具备妈妈般的温柔包容体贴（她本人已经习惯甚至乐意如此），细致关照身心健康，对忽视健康或过度透支的主角严肃叮嘱。
   - **街区全科诊所日夜背景**：小说模式及诊所场景支持昼夜切换（白昼明亮大窗，夜晚柔和暖灯），已无缝接入 `getNovelBackground`。
   - **小说模式医生对白立绘**：`src/frontend/fengjin-art.ts` 接入平静（neutral）、开心（happy）、严肃（serious）三款高清立绘，并自动回退衍生情绪。
   - **每周谈心疗愈服务（clinic-counseling）**：
     - 在商业区诊所或口袋公园心理谈心角，每周主角可找风堇医生谈心一次（跨游戏周严格受额度重置控制，四主角额度独立）；

   - **地点服务联动**：商业区/口袋公园「诊所全科问诊」与「风堇医生谈心」服务正式关联风堇医生，大模型提示词与叙事规则同步引导。
5. **四主角学籍与角色表述规范（修复高中生误读）**：
   - **全主角非在读高中生明确化**：在世界基调（`core.json`）与大模型提示（`bridge.ts`）中明确四位主角（素世、祥子、艾玛、玲奈子）均非在读高中生，四人各自沿用存档专业准备 2025 年 9 月 1 日架空秋季大一报到。
