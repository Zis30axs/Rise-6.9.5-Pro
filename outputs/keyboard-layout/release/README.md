# 全前端键盘布局修复版

- `unread-city-lite-tauri-keyboard.png`：TauriTavern 专用导入卡。
- `unread-city-lite.png`：通用 SillyTavern 导入卡，内容与 Tauri 卡相同。
- `unread-city-lite-assets.zip`：本次构建配套素材，通过卡内原有“安装 Lite 素材 ZIP”入口安装后刷新。

沿用既有酒馆助手安装与授权；已有可选 Live2D 素材包无需重新生成。键盘打开时整个前端保持位置与尺寸，靠下的控件可以被键盘覆盖，收起键盘后恢复可见。

验证报告见上级 `verification.json`。已做本地浏览器模拟与卡包一致性检查，未做物理 TauriTavern/iPhone 系统键盘和导入验收，未更新本机正式酒馆或存档。
