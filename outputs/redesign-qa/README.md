# 《未读之城》前端布局重构与四视口验收记录

## 1. 改动概览

本轮在 `lite` 分支正式落地全屏 Shell 与各功能面板的激进减法重构（对照已确认的设计稿），核心变化如下：

1. **常驻导航 14 → 5**：精简为 `故事`、`地图`、`手机`（常驻金色主入口，带未读消息角标）、`路线`（带可执行决议数角标）、`我`（带待回应邀约角标）。桌面端（`> 760px`）采用右侧 `80px` 垂直导航栏（`手机`置顶）；手机窄屏（`<= 760px`）采用底部 `62px` 固定导航栏（`手机`居中上抬圆形按钮）。
2. **桌面左舞台右书卷 · 手机三档抽屉**：
   - 桌面端左侧舞台完整留给场景背景与人物立绘（`SoyoLive2D`、`NovelNpcPortrait`、`NovelInvitationPortraits`），不再被居中弹窗遮挡人物面部；右侧书卷栏承载小说正文或当前打开的面板。
   - 手机端小说正文改为底部可拖拽/点按切换的三档抽屉（`peek` / `half` / `full`），兼顾立绘展示与沉浸阅读；地图、路线、个人页等面板在底栏上方全高展开。
3. **语境化「此处」互动条**：紧贴正文输入框上方，按当前所在地点动态列出可当面交谈人物、室内活动、下厨、店铺消费/打包、便利店/文具店/选书/公交乘车及相邻可达去处，替代原先独立的常驻「地点」导航按钮。
4. **单行顶栏与 `⋯` 菜单**：
   - 顶栏收敛为单行：`[地点 · 日期 · 天气 · 时间]`（点击直达地图）+ `[⚡精力]` + `[主角头像与姓名]` + `[⋯]`（`320px` 超窄屏自动隐藏主角姓名文字，保持零横向溢出）。
   - `⋯` 菜单集中承载四主角头像切换、正文字号（小/中/大）、画面方式（纯小说 / 3D 漫游）、刷新立绘与背景、角色方向开关（`让她自己决定方向`、`剧情参考已选路线`）、叙事与界面设置（含连接与布局微调）、开发环境调试入口、切换聊天与退出到酒馆。
5. **「路线」双页签（`RoutePanel.vue`）**：合并 `国策` 与 `决议`。国策页首屏直接展示可缩放拖拽的路线树与顶部当前进度条，点击节点从底部滑出详情抽屉；决议页改为分类筛选芯片 + 单行可展开条目 + 右侧金色 `⚡消耗` 按钮，移除重复列表与扫描线装饰。
6. **「我」四页签（`MePanel.vue`）**：按 `身心` / `随身` / `关系` / `手账` 收拢精力/精神/压力/健康/饱腹、学业课程与社交技艺、Appie Pay 余额入口、东都证券、学生证与关系图谱、衣柜、内嵌随身背包与珍藏装备、内嵌邀约簿、乐队/社交圈/联合体、手账本入口、专业课程表、日程与近期记录。
7. **「地图」单行工具栏**：合并地区选择、搜索框、目录、筛选、公交线路、立体/平面切换与关闭按钮；桌面端右侧显示地点详情栏，窄屏底部显示紧凑可展开地点卡。
8. **视觉与玩家可见文案清理**：采用暖黑金配色（`#0e1315` 底色、`#e7c584` 暖金、`#7cc0ae` 青绿、`#e3907f` 暖粉），全面移除玩家可见界面中的 ` // ` 英文工程副标题、`AI 托管`、`Open AI Map`、`演示内容`、`本地演示` 等开发或机制字样。
