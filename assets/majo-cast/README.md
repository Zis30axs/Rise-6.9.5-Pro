# 魔裁静态素材交接

本次先提交已恢复的 Twiitch 视觉素材及工程记忆，保持 PR #16 独立。

## 当前可用

`twiitch/` 共 13 张原生、自包含 SVG：四色应用图标（默认／素世／祥子／可可）、Twiitch 字标、可可猫咪频道头像、频道封面、离线卡片、透明直播边框，以及心形／星星／波纹／猫咪反应图形。配色和 96×96 图标尺度沿用仓库手机视觉资源的做法。

`manifest.json` 记录实际文件、MIME、大小及 SHA-256。`packs/unread-city-twiitch-art.zip` 使用 ZIP STORE、`assets/<sha256>` 和静态清单，只含数据，不依赖远程图片、字体或 CDN。它是后续接入用的增量素材包，尚未注册到现有游戏安装器，不能替换现行发行卡的完整资源 ZIP。
