# 第二批 Q 版角色表情素材（2026-11-14）

用户本轮提供 8 张 162×162 RGBA 透明 PNG，作为**独立备用贴图**保存。与已有 `assets/stickers/mygo/` 的五字母表情包并列存放，不覆盖旧素材。

- `chibi-01.png` 至 `chibi-08.png` 按用户本轮图片展示顺序命名（原文件名见 `manifest.json`）。
- 图片原始字节保留，未裁剪、压缩、重绘或调整透明通道；`manifest.json` 保存尺寸、哈希及稳定 ID。
- 暂不作具体角色身份绑定，避免未经校对把表情关联到错误 NPC。
- **仅储备素材**，未改手机聊天、Xitter 或纯小说 UI，也未加入最终单 PNG 构建；后续接入需复用现有本地资源打包管线，禁止新增外部 CDN 依赖。
- 来源为用户上传。原作者、授权和可再分发范围尚未核验，公开分发前需复核权益。
