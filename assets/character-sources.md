四个原压缩包合计 **87,548,265 字节**；四个输出 GLB 合计 **8,402,008 字节（约 8.01 MiB）**。按“全部原压缩包 → 输出 GLB”口径体积减少 **90.40%**。按“选定源模型文件 → 输出 GLB”口径减少 **94.82%**；这个源模型文件口径不含素世的外置贴图，不能冒称所有输入资源总量。输出 GLB 已包含实际使用的贴图，原包中未选用的 Blender 文件和预览图片不进入卡片。

- 将 PMX、VRM 转成通用 glTF 2.0，完整保留实际使用的骨骼与顶点权重；PMX 的 SDEF/QDEF 按标准线性蒙皮表达，不包含 MMD IK、刚体和布料物理。
- UV 参与几何简化，材质分组分别保留；素世适度减面，三个较高面数模型生成场景用 LOD。Claude 对 UV 岛接缝使用严格保护，同时以法线属性保护面部光照过渡，保留较高 UV 权重与六万面预算，避免跨接缝三角条纹和下巴块状阴影。只保留漫反射颜色贴图，去掉法线、金属度和专用 MToon/VRM 运行时扩展。
- 素世、深蓝少女、小洋使用最大 512 px 贴图；Claude 的单张颜色贴图保留原 2048 px 分辨率，保证面部细节。不透明贴图转 JPEG，透明像素仍用 PNG；保留材质的透明模式，素世透明贴图使用 MASK 或原材质 BLEND。
- 移除未使用的表情形态与形态动画数据；原素材均没有可用步行 clip。三个骨骼模型将上臂降至自然站立位置；Claude 保留原静态站姿。基础程序化步行不等于完整动作、表情或物理系统。
- 模型统一 Y 向上、正面 +Z、脚底 Y=0，居中并按场景身高归一化：素世 1.62 m、深蓝少女 1.65 m、小洋 1.62 m、Claude 1.05 m。它们是显示尺度，场景可以再按人物视觉设计缩放，不是人物叙事设定。

## 重建与检查

处理入口是 [prepare_character_models.py](../scripts/prepare_character_models.py) 和 [prepare_character_models.mjs](../scripts/prepare_character_models.mjs)。需要 Python 3.12、Pillow、numpy、py7zr，以及本工程锁定的 meshoptimizer/Three.js。依赖仅供维护时离线处理；导入角色卡不需要 Python 或原压缩包。

```powershell
python scripts/prepare_character_models.py 'C:\Users\Administrator\Downloads' '<临时工作目录>'
node scripts/prepare_character_models.mjs '<临时工作目录>'
```

输入压缩包由固定 SHA-256 校验，ZIP 解包限制路径、文件种类和总尺寸，7z 只允许已知的唯一 `DS.vrm` 成员。纹理引用限制在解包目录中，GLB 不允许外部 URI。转换检查索引、缓冲区边界、非有限数、节点循环、骨骼引用，以及最终落地与高度。

生成后仍须使用实际 Three.js 加载器检查外观、透明边缘、人物正反面、站姿和步行；构建成功和结构检查不能代替视觉验证。前端、角色卡 PNG、浏览器回归及真实设备验收由对应本轮记录区分；本资源处理本身不构成 TauriTavern 真机验收。
