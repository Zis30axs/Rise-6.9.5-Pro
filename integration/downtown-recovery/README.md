## 校验与发布约束

1. `tests/downtown-recovery.test.ts` 覆盖独立路线、返回、室内与位置、地图、小说模式等。相关旧模块 9 组定向回归见 `.github/workflows/downtown-recovery.yml`。
2. GitHub Actions 执行 `npm ci`、真实 Vitest 回归，以及从源码组合出的**基础** V2 PNG 世界书往返。它验证世界书已被构建，但不表示内嵌手机或完整 Tauri PNG 已合格。
3. 集成构建的 CI 使用**固定公开手机仓库基线** `Zis30axs/ST-iPhonie@24295193aa1adff606edcd4e63c8b07923533f2b`，便于测试可重现的前端构建。公开版本缺失用户后来在本机维护的部分人物建档/手机修改，CI 如能生成完整 Tauri PNG 也只能作为**预览产物**，禁止覆盖已获真机成功反馈的私人手机版本。
4. 最终完整发行必须仍从包含最新版用户私人手机源码的环境构建，连同新增图像验证 `zTXt` 无损转换、PNG 脚本一致性、压缩后严格 `< 50,000,000 bytes`。严格不把 bytes 与 MiB 混淆。
5. 桌面 1440×900、1280×800 以及手机 390×844、320×568 的浏览器布局实测仍然必须完成；GitHub CI 的纯状态/几何单元不能冒充四种视口或 iPhone TauriTavern 真机验收。
6. 不对原有世界书、老玩家存档、手机原生数据、原 PNG 产物做删除或覆盖。合并前需与 Work 的市中心素材分支和双主角 PR #4 比较冲突。

当前阶段是**功能恢复候选版本**，尚非最终有专属立绘和完全验证的角色卡发布。
