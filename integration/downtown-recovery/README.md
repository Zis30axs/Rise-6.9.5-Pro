# 市中心／丰川祥子恢复：阶段一

## 已提交的内容

1. `src/worldbook/toyokawa-sakiko.json`：四条启用的世界书条目，使用稳定人物 ID `sakiko` 与 `soyo`。明确家庭和解是**祥子与丰川家族**的后续分支，而非把和解偷换成仅与素世和好。原作背景、用户指定续作、当前运行时状态分开。恋爱关系不预设。现有 `scripts/build_card.py` 会遍历 `src/worldbook/*.json` 合入下一次卡片构建；本轮未声称独立叙事 API 已验证能收到这些条目。
2. `src/runtime/downtown-transit-policy.ts`：纯路线策略，不直接扣钱、移动人物或推进时间。保留三个旧目的地的票价／分钟；市中心线路为游戏配置 60 分钟、12 元，仅 ZBD-04A 可乘。跨外区经校园换乘；丰川家归属市中心站，其与市中心之间应步行，不绕回校园。显式选择 BTR-82A 时拒绝市中心线路，不偷偷换车。**尚未接入 model.ts、地图或乘车 UI。**
3. `scripts/release_budget.py` 与现有 Tauri 压缩打包器接线：对完整输出 PNG 强制检查 **严格小于 50,000,000 字节**，恰好 50 MB 也拒绝。检查在写产物和报告之前执行。报告记录限制、实际字节数与余量；原通用 PNG 保留，元数据与其他 PNG 块仍按原算法逐字节还原验证。
4. 可重复运行的测试：17 项 Python 与 12 项 Node，外加该独立 TypeScript 模块的 strict 检查。PNG 测试使用明确的 1×1 测试夹具，**不是游戏发行卡**。
