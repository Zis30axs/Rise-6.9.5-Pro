# 邀约簿独立入口

基于 `lite@a29cf390`，2026-11-01。

主界面工具栏新增「邀约簿」，状态页保留跳转入口。邀请与约定从状态页的小段列表移到独立的纸色卡片界面，提供近期约定、待回应、往期记录三类，展示人物头像、约定日期、时间、地点、邀请原文和公开回应。桌面采用左右两栏，窄屏上下排列，列表与表单可滚动。

新邀请可搜索全部联系人、选择日期与地点并填写活动。当面对方须在当前近距离人物列表中；其余时候使用短信邀请。完成表单后将自然语言草稿追加到既有正文输入框，仍由玩家决定继续故事。已有草稿不会被覆盖，也不会因打开面板或填写表单创建已同意邀约。

前往按钮复用原有 `travelToMeeting` 和 `runInteraction`，旅行时间、体力、车费、保存及失败处理由原流程结算。报价在按钮上方展示，失败时保留面板。原有正文赴约快捷按钮继续可用。

## 状态与边界

- 不新增存档字段、邀约协议、私人日程或模型请求。
- 共用 `socialInvitations`；当前主角发出的邀约，以及其他可操作主角发给当前主角的邀约，均在其本人的邀约簿中展示。
- 展示层只投影双方的约定与公开回应，不投影 `agenda` 的准备、实际抵达时间、私人取消或爽约决定。
- 「往期」不代表已经成功赴约；超出原赴约快捷入口的三小时时段仅显示「已过约定时间」。日期与相对时间都来自游戏时钟。
- 复用现有 `MapCharacterAvatar`；不更换头像或增加联网资源。新样式从 `shell.css` 内嵌到现有 Shadow DOM，不依赖额外远程样式表。
- 旧存档没有邀约字段时显示空页；切换主角/会话时清空本页的选择与邀请草稿。
