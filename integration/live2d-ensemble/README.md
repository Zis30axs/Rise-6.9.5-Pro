## 安装与回退

`assets/live2d-ensemble/unread-city-live2d.zip` 是独立、可选的素材包。角色卡仍使用原来的必需 `unread-city-lite-assets.zip`。运行时代码随新卡提供，新模型字节仅位于可选 ZIP。

在原生酒馆页面右上角点击“安装 Live2D 素材 ZIP”，选择本分支提供的扩展 ZIP。安装后可停用、启用或移除。安装器与原 Lite 入口同属父页面，聊天脚本 iframe 销毁后仍可操作，不依赖游戏 Shell 留在页面。父页面运行的是本仓库自带安装代码，ZIP 不能提供脚本。

未安装、停用、移除或当前模型失败时，保留原 PNG/表情差分和原有素世 Live2D；不增加衣着提示词。全包先逐项验证 SHA-256，再写入唯一激活记录；失败不替换旧激活记录。未激活的暂存内容以内容哈希存储，不能覆盖不同内容。重进逐项验证持久化数据；渲染前再次验证当前模型数据。只为当前服装创建 Blob URL，卸载释放其纹理和 URL，沿用 30 FPS、隐藏暂停/释放。

## 换装状态与叙事

按 `ShellModel.memoryScope` 的聊天身份隔离，使用兼容旧存档的本地键 `unread-city-live2d-wardrobe-v1:<session>` 保存人物、服装 ID、环境触发值和包版本。未启用包时不读写此状态，不修改 `WorldState` 或世界书。停用后记录休眠；重新启用沿用相同环境的选择。

选择由权威游戏日期、六小时时段、实际地点/房间、季节、`resolveWeather`、已知活动和小幅稳定人物偏好加权；同一聊天/人物/环境确定性抽取。服装类别权重归一，避免数量多的舞台服挤掉少量便服。主角个人存档提供其实际房间与活动；NPC 不借用玩家活动。只有现有现场名单内的人物和当前主角可以选择，离场人物不更新。演出倾向要求实际场地、已登记且到时的演出和成员资格；仅在 Livehouse 旁边不算演出。

同一服装状态交给单人阅读、NPC 立绘与赴约双人舞台，原有在场、邀约、视角和历史回看判断保留。确认状态只在当前渲染实例成功后建立，不持久化；重进先重新装载。切换环境、资源失败、卸载或禁用后，旧确认不再进入提示词。

正常主叙事调用独立追加“当前可见衣着”，与 Tavern、Chat Completions、Responses 的既有公共 system prompt 接线共用；不增加请求。只含现场且已确认人物，未确认身份不输出姓名，不含异地人物、资源文件名或算法。请求内同一人物旧静态 outfit 字段同步替换，避免与动态衣着矛盾；不修改世界书。手机回复、人物建档与自主短信不使用新增衣着指令。
