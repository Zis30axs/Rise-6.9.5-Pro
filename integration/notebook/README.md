# 《未读之城》· 人物手账

纯小说模式工具栏「手账本」支持翻阅、续写、编辑、保存与备份。

## 功能
- 全人物目录：四名可操作主角、已登记世界书居民及四主角已保存的联系人，用稳定人物 ID 去重。切换主角不切换世界档案。
- 玩家可从任何视角查阅任意人物手账，不需要物理接近或手机解锁；纯属全知旁观展示，**读手账不改变人物知情状态**。
- 当前主角可写本人手账；给其他人加内容时只能写「旁观备注」，不能冒名创造 NPC 的内心。
- 正常故事回复可选用一次 \`<notebook_pages>[{"personId":"bang-anon","title":"...","text":"..."}]</notebook_pages>\` 记录确实发生、值得本人记下的事情；每轮最多两人，每人一页，稳定人物 ID 必须已登记。只是可选协议，不保证模型每次都输出。
- 普通剧情请求不读取手账。玩家主动点击「帮我续写」时，仅为此次写作读取下方列出的片段；手账内容不作为 MVU 行动。
- 与 \`journal\`（最近一百条）、七日总结、长期记忆 Sidecar 分离。独立 IndexedDB \`unread-city-notebooks-v1\` 不主动裁剪旧页。记录 ID 绑定剧情回复 ID 方便避免重复，记录游戏日、分钟和叙事轮次。
- JSON 导入导出，可换机备份；导入按 ID 增量合并且拒绝未来页面。回档时只隐藏未来游戏时间/叙事轮次的页面，不在数据库永久删除，**同一时刻的分叉仍需要人工区分/恢复备份**。

## 写下一页
- 当前主角写第一人称，其他人物的手账仍只接受旁观备注。现稿与可选的写作提示一起发送，最多取两页同人物同视角的可见旧页，以及三段已保存的当前视角正文。旁观备注只带对应人物有参与证据的片段。
- 沿用玩家已配置的酒馆或独立叙事模型，使用单独的写作提示与输出校验。只在点击「帮我续写」后请求，返回编辑中的标题、正文分段、墨色、下划线与贴纸顺序。玩家点「保存这一页」才写入手账。失败、停笔与切换手账时保留先前草稿，迟到结果不落入当前页。
- `notebook-stickers.ts` 把贴纸标签和中文描述直接交给模型，例如 `mutsumi_unhappy` 对应若叶睦鼓脸，`mutsumi_smile` 对应若叶睦笑。角色身份用世界书的 `bang-mutsumi`。前端身份卡的 `romanizedName` 与贴纸目录各自维护。八张表情与五张字母贴纸复用仓库现有 PNG。
- 手写字体使用 [霞鹜文楷轻便版 v1.530](https://github.com/lxgw/LxgwWenKai-Lite/tree/v1.530) 的 Regular 款，离线 WOFF2 保留 GB2312、基本拉丁字符、常用标点及「睦」。授权随字体位于 [OFL.txt](../../assets/notebook/OFL.txt)。

## 边界与待验收
- IndexedDB 保存在当前设备浏览器容器；清理站点数据、更换设备或私密模式会造成数据损失。务必导出备份；空间满时应向玩家报告失败，不能假称永久云同步。
- 新剧情模型手账页先随剧情成功保存，再写 IndexedDB。若设备立即关闭或写入失败，正文仍保存，但**手账页可能丢失**（需补充与 Tavern-Helper 同步的持久 outbox 才能彻底解决）；失败会显示提示。
- 玩家手动续写与剧情本身附带的人物手账各走原有入口。NPC 在剧情有相关真实经历时仍可随同一轮正文附带手账，不在后台另发请求。
- NPC 未写过时显示空白本。没有自动为全体 NPC 补造历史。
