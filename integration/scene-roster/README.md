# 沙盘、地点与叙事共用在场名单

2026-11-15（1A + 21 + 3是）：废除室外 `35m / 18m / 7m / 3m` 距离截断，改为严格的「同地点 / 同房间」共处判定与低密度日常街景，并区分当前场景名单与地图熟人雷达。

## 规则要点

- **严格同地 / 同房共处（3是）**：`selectSceneRoster` 与 `worldSceneRoster` 要求室外成员与当前主角处于相同 `locationId`（室内则处于相同 `roomId`）；所有同地点/同房间可见成员均具备 `canTalk: true`。地点人物面板、3D 快捷搭话按钮、`model.ts` 对话/交换联系方式、手机权限与双立绘均不再以米制距离卡死。
- **日常街景低密度分流（1A）**：各常驻居民时段与散落地点覆盖校内与校外各区，标准街道与校门口最多展示 1–2 名普通在场居民，教学楼/图书馆/运动场/住宅区/商业街等较宽枢纽最多 2–3 名普通居民；随机行人只在街区偏冷清时补充 0–1 人。当前搭话对象（`encounterId`）、同行主角、已建档联系人与赴约到场/pin 访客始终受保护，不因人数上限被挤掉。
- **地点名单与地图雷达分离（21）**：地点窗 `[data-nearby-people]` 与模型请求的 `scene.nearbyPeople` 只包含当前地点或房间的在场人物，顺序与 ID 一致。地图雷达 `worldMapRadarPeople` 在当前地点复用 `worldSceneRoster`，在其他地点/城区仅展示其他可操作主角、已登记联系人以及已在约定地点现身的邀约对象，绝不远距离泄露陌生人或未到场的私人日程。
- **验证边界**：改动后需以本地 `vue-tsc`、相关 Vitest 用例与构建验证；未实测真实模型回复或 TauriTavern 真机环境前不得宣称通过。
