# 社交 Skills · 状态面板初版

本增量在原有状态窗口的「精神与压力」下方新增「社交能力 · Skills」，保留身体状态、学业、职业和历史面板。

## 六项技能

- `perception` 察言观色
- `empathy` 共情倾听
- `expression` 坦诚表达
- `persuasion` 说服交涉
- `organizing` 活动组织
- `mediation` 冲突调解

每项独立熟练度为 Lv.1–Lv.5。四主角初始能力各异，两个 INFP 也不会共用经验。MBTI 是初始表达倾向，不是强制人设或攻略限制。升级经验门槛为 0、40、110、210、350 点；每日最多练习经验 24 点。

## 数据层

权威状态为可选字段 `WorldState.protagonists.socialSkills`（`version:1`），四位主角按稳定 ID 各自保存 XP、当日经验和最近一次练习；`receipts` 保留最多 96 条回合 ID，避免同轮重复加经验。旧存档无此字段时填入确定性初始档案，不修改已有专业、钱包、故事及核心身心状态。

主 LLM 继续原本的小说叙事，仅在真实的人际练习时在原 `world_actions` 里附加一次 `social_skill`：
```json
{"type":"social_skill","skillId":"expression","deviation":2,"npcId":"某个已保存的联系人ID","reason":"本轮实际上发生的表达练习"}
```
如果尚无联系人，省略 `npcId`。`deviation` 为 0–3，按人物的完整性格、成长与语境评估。字段经过现有严格白名单协议验证，不解析小说正文关键词，也不增加独立模型请求。

`deviation` 对应额外精力消耗 0/1/3/5、压力增加 0/1/4/7，并由技能级别每两级减免 1（最低 0）。对应正向好感收益倍率 100%/90%/75%/60%，只作用于同 `npcId` 的 `relationship` 增益；负面好感不打折。技能 XP 每次增加 4–6 点，受当日上限和最大经验限制。不得以 `activity` 重复扣取这部分消耗。

## 边界

这轮提供的是存档、人物初始档案、状态页展示和剧情行动结算基础。Galgame 式邀约弹窗、可点击的自动选项、自定义回复入口以及邀约日程状态机 **均未在此增量中实现**；它们可以在后续阶段复用 `socialSkills`。未接入 Jev。也不接入 3D 场景。

## 验证

新增 `tests/social-skills.test.ts` 覆盖四主角隔离、旧档、正负好感、每日上限、幂等和白名单错误输入。远端 CI/Actions 未调用，未在本次环境完整检出仓库，因此尚未运行本地 Vitest、类型检查、桌面/手机实际浏览器渲染或 TauriTavern 真机验收；本分支不应据此声称已可发布。
