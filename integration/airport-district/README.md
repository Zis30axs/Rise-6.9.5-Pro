# 羽田机场区

## 用户提供的机场背景（2026-11-09）

小说模式在羽田机场使用 `素材/机场/` 提供的三张航站楼图片。按原游戏时钟切换：06:00–16:59 白天，17:00–18:59 黄昏，19:00–05:59 夜晚。只对应已有地点 `haneda-airport`，不新增航站楼房间、航线或时钟。

原始 PNG 的字节副本保存在 `assets/backgrounds/sources/haneda-airport/`；运行时使用原尺寸 1672×941 的无损 WebP，逐像素一致，三张合计 5,247,012 字节。`scripts/prepare_airport_backgrounds.py` 可重建，来源路径、SHA-256、编码参数和校验结果见 `assets/backgrounds/haneda-airport-source.json`。背景沿用现有居中铺满与夜间遮罩，窄屏仅按视口裁切，不改原图。

含背景的新交付目录为 `outputs/airport-backgrounds/release/`，对应的构建、测试和截图在 `outputs/airport-backgrounds/`；下方 `outputs/airport-district/` 保留此前仅沙盘增量的历史记录。新卡须配套使用新素材 ZIP。

推送范围为机场源码、原始素材与无损转制图、测试、文档和验证记录。按仓库现有忽略规则，构建中间文件及角色卡／ZIP 留在本地。历史浏览器记录对应当时完整工作区构建，包含同期的其他改动；此次机场独立提交另从暂存区导出源码副本，7 文件 20 项定向测试与类型检查通过，见 `outputs/airport-push/verification.json`。人物名单和装备相关改动保留在原工作区。

本轮背景与机场范围 6 文件 17 项测试通过；`vue-tsc --noEmit`、无假名检查和生产构建通过。系统 Chrome 加载最终 Lite IIFE 与 ZIP，在 1440×900、1280×800、390×844、320×568 四尺寸分别验证三张图片的真实加载尺寸、SHA-256、时段、游戏时钟不变及无模型生成，12 张截图已查看。320×568 的原有顶部控件会遮挡部分立绘，本次仅接入背景，未修改立绘布局。

扩展到诊所套件时总计 22 项通过、1 项失败：每周谈心测试在第 149 行报「国策时钟与权威时间不同步」。使用已提交的旧背景选择代码复测同样失败；测试及对应模型、主角、国策结算文件与 HEAD 一致。测试辅助函数只同步后台生活游标，未同步国策游标；本次不改诊所测试或游戏规则。完整记录见 [本轮验证](../../outputs/airport-backgrounds/verification.json)。未运行 Agent Edition、CI、真实模型、完整酒馆或 TauriTavern 真机验收，未安装到现有酒馆。

## 沙盘实现与此前验证

城市沙盘新增「羽田机场区」，点击城区标签或城市片区列表可进入详细沙盘。航站楼、登机廊桥、停机坪、静态客机、塔台、机库、滑行道与跑道均为本地几何，随现有沙盘加载与释放。机场位于城市模型南侧；仅在当前渲染树中隐去侵入机场范围的外围装饰楼实例，不改原 GLB、原城区建筑或存档位置。

入口复用已有 `haneda-airport`。地图图钉、当前地点与切换主角镜头指向同一航站楼；在羽田重新打开地图默认显示东京城市总览。南门交通站至机场仍为 50 分钟、¥1,200，羽田至旧金山仍为 600 分钟、¥48,000，返程沿原线路。地图浏览、缩放、旋转不提交世界行动；点击目的地继续走既有交互确认与旅行事务。未新增房间、航线、独立时钟或模型调用。

机场与加州目的地从校园地点列表分离，加州地点仍从世界地图与国际航线入口访问。塔台、跑道和停机坪只是景观，不作为可步行进入的游戏地点，不授予受限区域通行权。旧机场存档无需迁移。

实现：`src/frontend/airport-sandbox-layout.ts`、`airport-sandbox-geometry.ts`，以及既有 `map-districts.ts`、`campus-map-layout.ts`、`tokyo-sandbox-map.ts`、`CitySandboxScene.vue`、`WorldMap.vue` 的接线。原有在场人物名单与统一标签避让继续使用。

本地验证记录与截图在 `outputs/airport-district/`，交付以其 `release/` 为准；`build/` 是中间产物。定向 Vitest、`vue-tsc --noEmit`、Vite 生产构建，以及加载真实 Lite IIFE / ZIP 的系统 Chrome 四尺寸检查分别记录。浏览器测试操作真实地图和旅行按钮，处理既有随机事件确认，不生成或注入故事回复；环境航班计时器在测试初始存档中预设为一小时后，以隔离既有真实时间调度。

桌面浏览器验收不代表完整酒馆、真实模型或 TauriTavern 真机验收。未运行 Agent Edition、CI 或远程部署，未更新用户已安装的角色卡。
