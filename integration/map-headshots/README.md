# 地图头像独立裁剪

- 直接从仓库已有的角色原画（WebP/PNG/AVIF）制作 23 份 `assets/map-avatars/<人物ID>.svg` 头肩裁剪头像，统一 256×256 视窗。
- 旧 `assets/map-avatars/soyo.webp` 保留、不重建、不覆盖；23 份新头像也不会修改原有全身立绘。
- 头像是**自包含 SVG 裁剪视窗**，每份将对应原图二进制原样嵌入 `<image href="data:image/...;base64,...">`，属于源图裁剪，不是 AI 新生成，也不是重新编码的 256×256 WebP。原图可能自带背景。
- 地图角色优先按人物 ID 或姓名选择独立头像。若新 SVG 在某客户端加载失败，`MapCharacterAvatar.vue` 会退回该人物原来的立绘图，不把别人的脸当作占位。无素材者仍显示姓名缩写。
- `tests/map-headshots-assets.test.ts` 用原文件字节对照每一个 SVG 内嵌的图片，且检查素世原头像存在。本测试目前已写入仓库，尚未运行 CI / Vitest。
- 截至本次更新：最初已有的 22 人及后来新接入立绘的高松灯，共 23 份新裁剪。加上素世原头像，总计 24 张独立地图头像。
- 裁剪位置是按原图顶部中心设置，尚未逐人用真实客户端验收；如果有发型或脸部超出圆框，可逐人微调裁剪坐标。由于内嵌整张原图，这个做法侧重快速安全接入，资源体积并非最优；后续可在本地将 SVG 重新输出为裁剪 WebP 减小 Lite ZIP。
- 已禁止主动触发远程 CI/Actions。本更新未手动运行 CI、外部图片生成或 Agent Edition。
