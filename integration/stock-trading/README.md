# 东都证券

纯小说模式的 ST-iPhonie 首页在 Appie Pay 旁提供东都证券。每个聊天的四位主角各有证券账户，旧档首次查看时显示空账户。通过 Appie Pay 划转游戏日元后，可以买卖虚构证券。划转与账本分录一次保存。

在证券页选择证券后，可安排交易时段内的行情回顾。它和手机日历、纯小说今日日程共用同一条记录，两个日程入口均可打开对应证券。当前已接管的主角到点收到提醒，可在手机日历记录回顾。托管中或非当前主角的到期回顾由游戏时钟记入该主角的日记，不需要出行。

证券买卖、撤单和划转要求当前主角已手动接管。委托在交还托管或切走主角期间暂停撮合，收盘仍会自动到期，解冻资产。切回并接管后，下一次行情结算继续处理当天的有效委托。证券回顾不会生成交易委托。

行情按游戏时钟变化，周末与午间休市。虚构市场允许按股交易，资金和价格以整数日元结算。Appie Pay 沿用既有的整数分单位。

定向验证运行 `npx vitest run tests/stock-trading.test.ts`。手机界面由 `npm run phone:build` 编入现有单文件角色卡管线。
