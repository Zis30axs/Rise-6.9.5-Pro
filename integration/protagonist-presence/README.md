# 同地搭话与主角头像修复（2026-10-25）

用户复现：让两位主角前往运动场后，地点面板的搭话选项没有另一位主角，也看不到她的在场头像。用户明确指的是缺少搭话选项，不要求碰面后自动生成对白。

## 原因与改动

- 现场人口原来只有种子路人和常驻 NPC 日程，未合入素世、祥子的个人存档位置；艾玛也仍使用旧 NPC 日程坐标。现在 `world-presence.ts` 统一提供实际主角位置、现场人物与模型场景上下文，室内区分具体房间，排除当前主角自身。
- 搭话选择、保存校验和正文参与者记录接通同一人口。完整世界解析完毕后校验主角相遇，保留个人视角与原子结算；移动后清理失效相遇。艾玛历史 NPC 相遇可读取，但不作为新的在场证据或联系申请。
- 地图中的同地主角不受好感门槛限制；其他人物按当前主角联系人好感至少 10、现场距离不超过 35 米显示。头像重叠时分开按钮并画线指向实际位置。
- 浏览器复验发现进入城区后的 450ms 手势点击拦截会误吞头像点击；头像按钮现与地图控制按钮一样豁免，快速打开人物信息也有效。
- 3D 快捷搭话与地点面板统一使用 7 米，主角优先进入有限的快捷入口。模型人物也先筛附近再截取，避免主角被全量人口上限截掉。没有新增 3D 素材。
- 7 米内对白可进入在场人物的共同经历；明确选中的主角在交流时暂停后台自主行动。其他手机的近距离操作权限仍沿用原有 3 米规则。
- 点击“交流”准备输入，确认“继续故事”后生成；不增加自动模型调用。
