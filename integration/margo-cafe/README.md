咖啡馆到达、馆内活动、点单/打包或等待结束时，仍只在 PR #26 的门控允许后抽一次80%事件概率。同一主角全地点至少间隔180游戏分钟，每个游戏日最多2次选择，同地点的到达每天至多检查一次；未命中也进入冷却，拒绝消耗一次选择。额外限制咖啡馆每主角每天最多接受1份赠礼，按游戏日午夜重置，不按营业日重置；午夜仍须满足180分钟冷却。礼物来源按主角、游戏日、检查时刻确定，在场访客之外不会抽中其他人。

固定赠礼优先使用该次事件选择，无第二套额外抽样，不调用LLM。没有赠礼候选时沿用通用事件流程。玛格/访客不会获得玩家内心、其他主角日记、私聊或场外行动；仅艾玛与已登记旧识使用熟人表达。它不会自动创建联系人、交换联系方式或提高亲密度。
