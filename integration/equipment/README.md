## 归属与兼容

- 新档与旧档的素世、祥子各持有一张未装备合照；重复加载不增发。艾玛、玲奈子不会获得合照。
- `inventory[].equipped` 随原有个人背包保存；主角切换沿用 `personalKeys`。后台个人视图显式传递主人身份。
- 学习进度原本允许半点；新增倍率可能产生四分之一点，因此按四分之一点精确保存。历史收益保存版本化效果 ID，卸下装备后仍可校验旧收益；调整倍率时需新增版本，不能改写既有版本。
- 社交 XP 保持整数，零头以 0–3 个四分之一点按人物和技能分别保存。卸下不会丢失已获得的零头；达到原有每日或总经验上限时不积攒超限收益。
- 同轮装备、学习、交流、卸下按行动先后确定倍率。任何非法操作沿用原有事务回滚与重复回合保护。
- LLM 只接收当前装备事实和人物描述，不能直接提交倍率或经验值。合照不能作为消耗品使用或赠送。
- 目录、装备状态和效果计算分离；黄瓜、金平糖及遥奈伪装留待明确设计，不加入召唤或传送 NPC 的行为。
