# 樱羽艾玛 · 第三主角

本分支在 PR #18（魔裁视觉接入）之上增加第三个可操作主角。角色卡、世界书、存档和美术沿用现有架构；没有新增联网服务、模型调用或在线素材下载。

## 可操作身份

- 主角列表：`长崎素世 / 丰川祥子 / 樱羽艾玛`。
- 稳定人物 ID：`majo-emma`；只在这一个映射处接管原常驻人物：
  `PROTAGONIST_PERSON_IDS = { emma: 'majo-emma' }`。
- 三人共享同一条世界时钟和同一段已保存历史；切换不改写另一个人的位置、背包、账户、手机、日程、联系人、日记或故事。
- 当前主角独占前台；另外两人保存在 `inactive` / `third` 两个个人状态中。切换时按规范顺序重排，不复制人格。

## 存档

- 新存档版本：`1.13.0`。
- 1.12 双主角存档在原位升级：`inactive` 原样保留，新增 `third`（艾玛）、第三个 Appie Pay 账户与设备、后台生活第三人；艾玛只创建一次。
- 1.0–1.11 旧卡首次进入主角系统时直接创建 1.13 三人状态；素世仍使用原前景状态。
- 旧存档中的艾玛待人接物、联系人和短信历史保留；升级不重放、不补发、不重复结算。
- 余额仍由 Appie Pay 整数分账本投影；三人各自校验，不能靠切换改余额。

## 切换行为

- 切换保留三人各自的位置、室内/室外、移动记录、体力、余额、背包、学业、手机、联系人、日程、日记和故事。
- 选择目标主角后，小说视图立即显示该主角的立绘：素世使用 Live2D，祥子与艾玛使用各自 sprite；随后由本轮实际说话人接管对白立绘。
- 3D 场景只显示素世的角色模型；祥子/艾玛不伪装成素世模型。
- 当前主角在场景中时，不再作为背景 NPC 被投影、搭话或群聊抽样；她的 NPC 短信发送会被拒绝并提示使用主角短信或切换手机。
- 后台生活对另外两人分别结算：位置、日程、体力、手机通知和已保存记录互不覆盖；两人都在同一场景时以当前前台叙事为准，不继续私有自动化。

## 手机与记忆

- 三人各自有手机设备 ID、Appie Pay 账户、主题（`soyo-soft` / `sakiko-blue` / `emma-soft`）、通知、日程、订单和审计记录。
- 主角短信支持显式收件人：`send_message` 可带 `to`；手机“世界消息”列出另外两位主角。回复只写回原会话，不自动触发新回复。
- 七日全局记忆、后台生活事件和共同经历继续按 `owner` 隔离；全知周报只做摘要，不变成某个主角已知事实。
- 艾玛的手机视觉当前使用艾玛配色与回退图标；专属手机壁纸/图标素材缺失，未虚报为完成。

## 实机文案

- 住宅与室内描述已删除“游戏原型/不作为官方住宅设定”等实机注释；这些边界只保留在开发文档，不进入玩家可见文本或叙事提示。
- 未分配专属素材的常驻人物仍使用通用住宅室内，但界面不再声明“原型”。
