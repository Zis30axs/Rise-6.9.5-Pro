# 未读之城 · 山海都会

## 第二版：重建城市本体

本版根据用户明确允许大改地形、城市布局、高架与轻轨的要求，重新搭建海湾都会。上一版沿用旧地图平铺结构，本版的地形、建筑、交通与镜头均由新的共享模块生成。

### 视觉与交互

- 起伏山脊、分层岩壁、海湾与弯曲河道、沿岸沙滩和 250 棵确定性生成的树木。
- 123 栋建筑，包含退台金融塔、八角玻璃塔、双塔空中花园与圆环观景塔；普通街区有裙房、窗格、坡屋顶与设备细节。
- 金潮双塔悬索桥、两侧引桥、实体桥墩和曲线匝道。
- 独立高架轻轨环线、三座带玻璃弧形雨棚的车站、连接街面的楼梯，以及三组四节列车。
- 贝屿艺术中心、滨水步道、码头、游艇及两艘动态水上巴士；高速公路有 19 辆动态车辆。
- 日落金辉、晴空日光、蓝调时刻、万家灯火四套光照。
- 七个地标飞入视角、自动漫游、缓慢环绕、图层开关、PNG 风景导出；支持拖动、双指缩放、滚轮和方向键。

### 项目接线

`src/frontend/metropolis/` 是项目与 Site 共用的实现：

- `terrain.ts`：可采样地形、水岸裁切、森林与底座。
- `urban.ts`：建筑群、桥梁、轻轨、码头与导览地点。
- `geometry.ts`、`types.ts`：场景数据与几何工具。
- `renderer.ts`：Canvas 透视投影、面排序、材质、窗格与交通遮挡。
- `CityStage.vue`：相机、交互、漫游、尺寸适配和图片导出。
- `MetropolisApp.vue`、`metropolis.css`：展览式城市界面。

`WorldMap.vue` 默认显示新的山海都会。右上角“世界与行程”打开 `WorldMapJourney.vue`，该文件是上一版地图的完整副本，继续接受相同的 model/actions/novelMode/refreshToken，并转发 travelled。新的概念城市地形与地标没有强制对应原剧情地点；实际出行继续通过既有行程界面完成。

新样式以 `.metropolis` 为范围，并由 `shell.css` 带入角色卡的 ShadowRoot。宿主使用独立前缀，预览与项目共用同一份组件，不再复制一套简化场景。

### 独立 Site

入口 `preview/city-sandbox` 直接加载 `MetropolisApp`。它不导入完整角色卡运行时、人物素材或旧 GLB；不读取酒馆聊天与存档，也不发出剧情模型请求。所有地形、建筑与动画由本地代码生成，完整浏览器效果不依赖 WebGL。

```sh
npx vue-tsc -p tsconfig.city-preview.json --noEmit
npx vite build --config vite.city-preview.config.ts
```

默认输出 `dist/city-sandbox`。Sites 发布副本显式将产物目录设为 `dist`。既有 Site 链接继续使用，访问范围保持原有仅拥有者设置。

### 验证边界

本次进行了预览范围的严格 Vue/TypeScript 检查、生产构建、确定性场景几何检查及真实受控浏览器检查。几何检查确认坐标有限、轻轨闭环、引桥端点位于陆地。浏览器检查覆盖 1440×900、1280×800、390×844、320×568 四个尺寸，均无页面横向溢出；320×568 也没有页面纵向溢出。另验证了光照、地标飞入、返回全景、自动漫游推进、拖动旋转、图层开关与真实 PNG 下载。

渲染使用 Canvas 深度排序和局部交通遮挡，极近距离相交曲面仍可能出现细小排序误差。没有将静态预览测试当作完整角色卡、真实模型或 TauriTavern 真机验收。本轮没有重打卡包、安装到酒馆或合并进 lite；源码在原功能分支/草稿 PR 供审阅，提交使用 `[skip ci]`，没有触发远程 CI 或 Agent Edition。
