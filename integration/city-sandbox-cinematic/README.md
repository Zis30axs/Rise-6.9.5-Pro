# 城市光影沙盘

本轮基于 `lite` 的 `f7573962739b3c4ff5d6dac3523d44abd5dbff0a`，把城市地图改为深蓝、香槟金的模型展台风格，并提供同源 Vue 浏览器预览。没有变更角色卡存档结构、地点 ID、旅行费用、公交规则、人物位置或剧情模型协议。

## 改动范围

- `src/frontend/WorldMap.vue` 与 `world-map.css`：城市标题、分区目录、地点卡片、相机与天色控件、桌面与窄屏排版。保留城市、所在区域、世界三个入口及返回城市时恢复视图的行为。
- `CitySandboxScene.vue` 与 `tokyo-sandbox-cinematic.ts`：保留现有离线 GLB、交通、飞机与索道，在渲染层添加分层展台及金色轮廓。相机、坐标转换、地点拾取、地图比例尺与旅行事件仍使用原有接口。
- `tokyo-sandbox-canvas.ts`：WebGL 创建失败或上下文丢失时，用独立的新 Canvas 绘制同一城市元数据的透视模型。建筑包围尺寸、道路、城区与地点投影来自现有数据；窗格、树木和灯光仅用于表现。此路径不解析 GLB 内全部细节，不等同于 GPU 模型的完整视觉复刻。
- 兼容渲染器使用同一个 `THREE.PerspectiveCamera`，保留平移、旋转、缩放、俯仰、城区飞入、地点点击与比例尺。按设备原生 DPR 绘制，不因缩放或相机飞行降低分辨率；静态场景按相机和天色缓存，动画帧只更新车流等效果。
- 移除地图中的人工演示人物定位入口，地图人物继续由实际在场信息和既有好感可见性规则产生。

## 独立预览

预览入口位于 `preview/city-sandbox`，直接导入上述项目组件及既有运行时。初始状态是固定的浏览样例，不读取酒馆、真实聊天或玩家存档，也不连接剧情模型。预览中的旅行仍由项目现有状态归约器结算，结果仅保留在该页面内存里。

局部构建使用 `vite.city-preview.config.ts`。它独立于完整角色卡发行脚本，不运行手机打包、Agent Edition、自跑戏或远程 CI。预览构建对浏览器图片采用静态资源，对离线 GLB/ZIP 保留既有受限资源读取方式；不放宽 `readLocalAssetBytes` 的 URL 规则。

```sh
npm ci --ignore-scripts
npx vite build --config vite.city-preview.config.ts
```

Site 使用同一批源码和资产的独立发布副本，默认仅拥有者可访问。原角色卡仓库的改动在功能分支上供审阅，不自动合并到 `lite`，不生成或声称已经安装发行卡包。

## 验证原则

本轮只进行定向本地静态检查、地图相关单元检查及独立预览的受控浏览器检查。本地 8 个地图相关测试文件共 39 项通过，独立预览的严格 Vue/TypeScript 检查通过。本轮 16 个改动文件的假名扫描为零。受控浏览器实测 1440×900、1280×800、390×844、320×568，均无页面横向溢出；验证了城市/城区切换、地标进入、返回、缩放、旋转、天色切换及南门到图书馆的 15 分钟旅行。

当前浏览器不提供 WebGL，因此浏览器实测覆盖的是自动 Canvas 兼容路径；GPU 路径已通过类型与场景/恢复单元检查，未冒称 GPU 浏览器验收。全项目类型检查因稀疏检出中缺少 Live2D 与 embedded-phone 生成资源而阻断；全项目 `no-japanese` 测试因未检出历史 `outputs` 目录而阻断，未把局部扫描记作全项目通过。浏览器桌面与手机尺寸检查不等于 TauriTavern 真机、真实剧情模型或完整角色卡发行验收。

远端提交使用 `[skip ci]`。不派发 GitHub Actions，不运行 Agent Edition。
