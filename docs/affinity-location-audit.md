# 大学篇地点彩蛋核对

最初的 37 个地图入口对应 20 人的 30 条互动。一条互动可以发生在两个地方，例如爱音既可以逛商场，也可以去水族馆。下表按原始入口逐项记录，右栏说明当前小说模式在什么情形下能用。阳光水族馆、图书馆自习室和王冢宅邸在补丁前已经存在，另列在表后。

| 原入口 | 地点与当下人物的关系 | 游戏里的处理 |
| --- | --- | --- |
| 飞鸟山公园·喷泉广场 | 北区公园确有喷泉，原稿把广场写作素世和祥子的旧事地点。 | 素世在王子站侧公园入口和广场都有反应，祥子只在喷泉广场回忆旧事。 |
| 都电荒川线·学习院下至飞鸟山 | 两站在同一条都电线上，扶稳、看窗外、多坐两站都发生在乘车途中。 | 原文保留。现有高田至公园的地区接驳已可乘坐，尚未记录学习院下至飞鸟山这段都电的车内同行，暂缓触发。 |
| 池袋客服中心楼外 | 祥子的旧工作可以被提起，当前档案没有这处客服中心的在职班表。 | 保留原文，等当前剧情和班表确立后再开放探班。 |
| 羽丘旧音乐室·琴房 | 高中琴房有前史，毕业后的旧生进校、使用琴房要有到访缘由。丰川宅会客厅已设钢琴。 | 现在的陪练放在丰川家，须受邀并遇到祥子愿意弹琴。 |
| 千登世桥 | 东京都交通局将桥列入学习院下站周边。灯和爱音今天仍可以到这里散步。 | 保留，爱音可以自己说起高中追队友的往事。 |
| 南池袋公园 | 丰岛区公园，草地和步道成立。 | 保留灯的散步互动。 |
| 池袋满天星象仪·天文馆 | Sunshine City 内有满天天文馆，可观看圆顶放映。 | 灯与初华用馆内反应，室内看星空不要求当晚天气晴朗。 |
| 池袋 Sunshine City 商业街 | 原稿所写挑衣服对应室内购物区 alpa。 | 爱音的挑衣服和逛街合照在商场触发。 |
| 羽丘放学路 | 爱音已是大学生，不能凭一个叫作“放学路”的入口生成高中日常。 | 同行用千登世桥。没有替她指定大学、校区或通勤路线。 |
| RiNG 前台 | 卡内世界书把 RiNG 设在池袋，立希在此打工，麻里奈按排班跨店协助。 | 前台接入两人的实际班表。立希 16:00 至 22:00 当班，最后一小时可出现等她收班的反应。 |
| 大塚站旁家庭餐厅 | 大塚站北口有可供两人坐下用餐的家庭餐厅。 | 恢复室内餐桌场景，沿用原地点编号。现实门店只用于核对场所，剧情不指定立希的常去门店。 |
| 家庭菜园·黄瓜花坛 | 睦的当前特质写有自家阳台种瓜，个人目标也有照料菜畦的日常。 | 原文保留。若叶家目前没有受邀探访的可达场景；旁人经过住宅区或收到她送的黄瓜，都不等于去过她家。 |
| 演艺后台候场区 | 后台涉及出演安排和进场权限。 | 复用新宿演出现场，核对当日阵容；开演前半小时，睦本人在场可交谈时，采用在公众可到区域陪她候场的反应。 |
| 正式表演场馆外 | 演出陪伴需要落实到某场演出和出演者。 | 与上项共用场次条件。RiNG 前台普通探店不会触发睦候场。 |
| 抹茶甜品专门店 | 池袋东武百货的茶寮翠泉在游戏开篇前已有抹茶芭菲。 | 恢复甜品店。乐奈分冰淇淋的反应只在这里，须实际点了甜品。 |
| RiNG 门口 | 同一间现场屋的街面入口，可以听见门内有人弹琴。 | 乐奈闻声靠近的反应保留；门口不自动出现芭菲或甜点座席。 |
| 安静的天台 | 原稿没有给出具体建筑或可到达的屋顶。 | 乐奈抱琴晒太阳可在有日光的公园发生。 |
| 公园长椅 | 既有口袋公园、城市公园各有长椅。 | 乐奈看日光，月代雪看降雪或黄昏；同一张长椅可以有不同反应。 |
| 高楼观景天台 | Sunshine City 的阳光60展望台是室内观景层。 | 恢复为窗边看晴夜的地点，互动窗口取 19:00 至 21:00 之前。在满天看的仍是放映。 |
| 御茶水乐器街 | 千代田区旅游资料有乐器店街，能逛琴行、看琴弦与效果器。 | 保留海铃的逛店反应。 |
| Livehouse 排练室走廊 | 卡内已有 CiRCLE 隔音练团室。 | 用该练团室承接排练间隙的聊天。挑弦留给逛店情境。 |
| 原宿·表参道美妆快闪店 | 街区存在，快闪店的举办时间要看当期档期。 | 保留商业街上的逛店、穿搭与拍照。本次未指定一场常开的快闪。 |
| 打卡咖啡馆 | 可以在现有街边咖啡馆帮若麦取景。 | 选好角度、店内允许拍摄且确实拍了素材时采用。 |
| 昏光庭院·阳光草药圃 | 庭院和小伊卡属于风堇原稿；本作另有明确的东京街区全科诊所。 | 东京的休息互动放在口袋公园，晴朗午后可喝茶。不把原作庭院、草药或小伊卡放到诊所门外。 |
| 中学旧校舍走廊 | 艾玛的中学经历是人物前史。当前东京地点没有对应旧校舍的到访记录。 | 艾玛主动提起旧事时可以谈；普通校园走廊不会让她自动经历一次重返旧校。 |
| 安静庭院 | 游戏图书馆已有室外前庭，能坐下陪艾玛。 | 复用前庭；只有她自己愿意开口才涉及往事。 |
| 安静茶馆 | 希罗整理资料可以有饮茶和自习两种情境。 | 恢复茶寮分支。茶寮有茶具时可续茶；自习室里只约离开后喝茶。 |
| 芦谷高校天台 | 对玲奈子而言这是旧校的特定回忆。 | 大学篇想躲开人群时可以去口袋公园，旧天台可由她提起。 |
| 秋叶原电玩主机店 | 秋叶原有电器街和专门店。无需钦定某家是玲奈子常去的店。 | 地图停在街区，实际进店看主机时采用。 |
| Queen Rose 精品街 | 世界书支持家族品牌和王冢宅邸里的当季服装，未给出整条冠名精品街。 | 受邀到王冢宅邸时可以看服装或一起做饭，具体活动由当场剧情决定。 |
| 神保町旧书店街 | 神保町是东京的旧书店街。 | 保留纱月挑书、交换书单的反应。 |
| 安静咖啡书吧 | 南池袋公园的咖啡餐厅二楼确有整面书架。 | 恢复书架旁喝咖啡聊书的地点，与神保町买旧书各有入口。 |
| 池袋乙女路 | 乙女路及沿街周边店常设开放，香穗可以和人逛街。 | 保留逛店反应。外拍另看星来是否到场、是否在当时当地有拍摄安排。 |
| 漫展 Cosplay 会场 | Sunshine City 文化会馆有实体展厅。AGF 2025 主会场的实际展期是 11 月 8、9 日，每天 09:00–17:00。 | 地图提供展厅入口。用游戏日期和展期核对漫展；散场后半小时内，只有确曾参加并与香穗一起离场时才采用摘隐形眼镜的反应。 |
| 住宅区商店街超市 | 杂司谷二丁目有超市，濑名家在卡内也住在杂司谷。 | 恢复超市，买菜反应只给在店里一起挑食材的两人。 |
| 鬼瓦洗衣店 | 卡内住房资料明确一楼营业、二楼起居；星来的当前档案另有她自己的在读学籍。 | 保留一楼店面和熨衣反应。不据同伴升学改写星来的身份。 |
| 漫展外景拍摄地 | 外拍是活动，要约定地点；乙女路是本次采用的池袋室外场景。 | 与星来同场、当前主角日历有当地外拍安排时才提供条件性提示，实际拍摄还看双方意愿和现场条件。 |

已有的阳光水族馆继续承接灯的企鹅、水母和爱音的参观合照。图书馆自习室继续承接希罗的整理资料。王冢宅邸已有 Queen Rose 礼服。三者都复用现有地点。

地点核对不等于动画取景认定。家庭餐厅、茶寮、超市、展望台和公园咖啡馆用于安放这份互动原稿；没有把它们认定为角色在原作到过的店。观景时段、演出前半小时和展览散场后半小时是本作选择彩蛋的时间窗。
