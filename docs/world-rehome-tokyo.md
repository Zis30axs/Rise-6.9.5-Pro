# 东京世界线迁移草案（尚未实施）

本仓库目前仍是使用“元”、中国风格公交和 2025-09-01 大一报到的游戏原型。此文件仅是 2026-10-23 玩家提出的迁移方向，不代表 lite 地图和货币已搬至日本，也不是原作住宅地址的官方证据。

- 东京丰岛区**池袋、东池袋**：MyGO 活动、音乐演出、商圈、RiNG 及现代商业空间原型。
- **杂司谷、高田**：魔裁幸存者的公寓、泽渡家老宅、宝生玛格经营的复古占卜咖啡馆及旧街巷日常。
- **目白、目白台**：文教与安静住宅圈，可作为二阶堂传统宅邸和丰川旧居的 *改编* 原型，不硬指认角色准确住址。
- **早稻田周边**：书店与虚构校园的参考，不等于官方学校坐标。

工程迁移时保留已有 locationId、室内 ID、人物 ID 与存档；地图标注、道路、交通工具、币种、价格、学校学期分别迁移并测试。不能直接把人民币余额数字原封不动地当日元；不能把 BTR-82A/ZBD-04A 无解释地当作日本公交。2025-09-01 大一报到不符合多数日本高校春季入学节奏，未来应解释为架空的秋季入学批次或独立调整学年，不在节日功能里偷偷更改历史游戏时钟。

本轮日历新模块先实现 2025–2027 日本正式节假日、民俗节庆和世界书已有生日，并在叙事/课表 UI 中生效；不搬迁现有地图经济。
