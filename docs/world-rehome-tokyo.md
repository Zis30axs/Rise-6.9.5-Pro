## 日元与旧存档

全新的世界状态写入 `currency: 'JPY'`。没有货币字段的旧存档按 **1旧游戏元 = 20游戏日元** 一次性换算，保留旧交易及乘车的历史事实。这是游戏固定迁移系数，并非实时汇率：同步换算个人余额、三主角 Appie Pay 各卡余额、原卡交易流水、旧订单以及后台生活的待结算旅行费。已迁移存档重复读取不再二次换算。旧日志不改写文本内容。

新档初始金钱：素世 ¥6,560、祥子 ¥24,000、艾玛 ¥12,000。店铺/餐饮/打包/配送等数值采用日元。旧交通车辆 ID `btr82a` / `zbd04a` 仍用于历史存档，新界面显示都营巴士／东京Metro接驳，街上改为民用车辆简化建模、不加载原军用 GLB。

保留**2025-08-28 17:20**开局和**2025-09-01**的三主角校园线架空秋季大一报到日期，不改变原有日历与任务进度。邦邦与魔裁阵营初始互不认识，只有剧情内接触才能建立关系。
